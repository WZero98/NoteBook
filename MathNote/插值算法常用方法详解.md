## 零、预备：插值问题的统一表述

### 0.1 问题定义

给定**节点**（knots / nodes）$x_0 < x_1 < \cdots < x_n$ 及对应函数值 $y_i = f(x_i)$，插值问题要求构造一个函数 $S(x)$，满足**插值条件**：

```math
S(x_i) = y_i, \qquad i = 0,1,\dots,n
```

并在节点之间的子区间 $[x_i, x_{i+1}]$ 上用来近似 $f$。

- **插值（interpolation）**：$x$ 落在数据范围内（$x \in [x_0, x_n]$），要求过点。
- **外推（extrapolation）**：$x$ 落在数据范围外，误差不可控，需谨慎。
- **拟合/逼近（approximation）**：不要求过点，最小化整体误差（最小二乘、样条平滑、正则化）。

> **名词约定**：工程文献中，"spline" 有时泛指**分段多项式**，有时特指**具有 $C^2$ 连续性的三次样条**。本文用「分段多项式」表示更广的类，用「样条」指具有跨节点连续性约束的分段多项式。

### 0.2 插值方法的四个评价维度

| 维度 | 含义 | 影响 |
|------|------|------|
| **精度阶** | 当 $h = \max_i (x_{i+1}-x_i) \to 0$ 时误差 $\|f - S\|_\infty = O(h^p)$ | 决定网格加密时的收敛速度 |
| **光滑性** | $S \in C^k$ 的最大 $k$ | 影响导数/曲率是否连续、是否有可见折角 |
| **形状保持** | 是否保单调、保凸、不产生过冲（overshoot） | 图像、浓度、概率等物理量常必须保形 |
| **计算代价** | 建表/预处理的复杂度 + 单点求值的复杂度 | 实时系统、GPU、嵌入式中的关键约束 |

后文各方法按这四个维度对比。

### 0.3 多项式插值的理论边界：Runge 现象

如果用一个 $n$ 次多项式**整体**通过 $n+1$ 个等距节点，高次多项式会在区间端点剧烈振荡，误差不随 $n$ 增大而减小——这就是 **Runge 现象**（Runge, 1901）：

```math
f(x) = \frac{1}{1+25x^2}, \quad x \in [-1,1]
```

等距节点上的插值多项式在端点附近误差趋于无穷。两条经典解法：

1. **分段低次多项式**（分段线性、样条）——牺牲全局光滑性换取局部性与稳定性；
2. **Chebyshev 节点**——节点在端点加密，使 Lebesgue 常数增长最慢。

**这正是分段方法的根本动机**：与其用一个高次多项式强行通过所有点，不如用许多低次多项式拼接，再用连续性条件把它们"缝"起来。$C^0$ 缝合得线性插值，$C^1$ 缝合得二次/三次样条。

参考：Runge C. *Über empirische Funktionen und die Interpolation zwischen äquidistanten Ordinaten.* Zeitschrift für Mathematik und Physik. 1901;46:224–243.

## 一、最近邻插值

### 1.1 原理

最近邻插值（Nearest-Neighbor Interpolation，又称 **Voronoi 插值**、**零阶保持**、**piecewise constant interpolation**）是最简单的插值：把每个查询点 $x$ 赋给**距离最近的节点**的函数值。

```math
S(x) = y_{k}, \qquad k = \arg\min_{i} |x - x_i|
```

等价于：在区间 $[x_i, x_{i+1})$ 上，$S(x) \equiv y_i$（若取左端点）或按中点分裂（更常见的对称定义）。

**中点分裂形式**（更对称）设 $m_i = (x_i + x_{i+1})/2$，则

```math
S(x) =
\begin{cases}
y_0, & x < m_0 \\
y_i, & m_{i-1} \le x < m_i \\
y_n, & x \ge m_{n-1}
\end{cases}
```

### 1.2 误差与性质

- **精度阶**：$O(h)$（在 $f$ 连续可微且 $f' \neq 0$ 处），误差为 $O(h \cdot |f'|)$ 量级。注意这个阶只有**一阶**，且当 $f'$ 很大（陡峭处）误差显著。
- **光滑性**：$S \in C^{-1}$，在每个中点处**跳变**（值不连续）。这是它最致命的缺点。
- **形状保持**：保单调（不产生新极值），但会产生**台阶**（blockiness）。
- **计算代价**：$O(\log n)$ 查找（二分）+ $O(1)$ 求值；可完全向量化，GPU 友好。
- **过点性**：是，节点处精确。

### 1.3 变种与工程实现

| 变种 | 说明 | 典型场景 |
|------|------|----------|
| **Voronoi / 最近邻分类** | 多维空间中把点划分到最近样本，等价于 1-NN 分类器的决策区域 | 分类、区域划分 |
| **K 近邻（KNN）加权** | 取 $k$ 个最近点的加权平均，退火为"平滑近邻" | 散点平滑、非参数回归 |
| **零阶保持（ZOH）** | 数字信号处理里的采样保持 | DAC 输出、阶梯波形 |
| **像素级最近邻缩放** | 图像 resize 的 `nearest` 模式 | 分割 mask、标签图、像素艺术 |
| **K 近邻在 GPU 上的实现** | 用空间哈希 / 网格分桶替代逐个距离计算，$O(1)$ 查询 | 点云、粒子系统 |

**伪代码（1D，含中点分裂 + 二分查找）**：

```text
function nearest_interp(xs, ys, x):
    # xs 升序，长度 N；返回 S(x)
    N = len(xs)
    if x <= xs[0]:   return ys[0]
    if x >= xs[N-1]: return ys[N-1]
    i = binary_search(xs, x)                  # 最大的 i 使 xs[i] <= x
    # 中点判断：靠近 xs[i] 还是 xs[i+1]
    if x - xs[i] <= xs[i+1] - x: return ys[i]
    else:                        return ys[i+1]
```

**复杂度**：预处理 $O(1)$；查询 $O(\log n)$（二分）或 $O(1)$（若网格等距可直接整除取整）。

**等距网格上的 $O(1)$ 特化**（图像/体数据的关键）：

```text
function nearest_grid(x, x0, dx, n):
    i = round((x - x0) / dx)       # 直接四舍五入
    return clamp(i, 0, n-1)
```

### 1.4 应用情形

**适合：**

1. **标签图 / mask / 索引图的重采样**——这是最近邻最重要、也几乎唯一"必须"使用的场景。语义分割 mask、实例 ID、深度图的类别标签都是**离散类别**，线性插值会创造出"类别 1 和类别 2 的平均 = 1.5"这种无意义的中间值，破坏标签语义。
2. **查找表（LUT）式的阶跃映射**——颜色量化、调色板映射、阈值分段。
3. **需要极低延迟且可接受台阶的实时系统**——嵌入式、FPGA 中的粗采样重建。
4. **散点所属区域判定**——Voronoi 划分、最近邻分类。

**不适合：**

1. **连续量重建**（图像灰度、传感器读数、物理场）——台阶会引起视觉块效应与数值上的不连续，后续求导/滤波会放大。
2. **需要导数或平滑性的场合**——$C^{-1}$ 连续性使得任何基于差分的操作都会在中点处爆炸。
3. **高精度数值积分**——阶跃函数的积分收敛极慢。

> **一句话**：最近邻是**唯一正确的离散标签插值**，却是**最差劲的连续量插值**。选它之前先问：这个量在物理上是连续的，还是离散类别的？

**文献**：最近邻插值的几何基础见 Voronoi 图的原始工作（Voronoi G. *Nouvelles applications des paramètres continus à la théorie des formes quadratiques.* Journal für die reine und angewandte Mathematik. 1908;134:198–287. doi:[10.1515/crll.1908.134.198](https://doi.org/10.1515/crll.1908.134.198)）；图像重采样中的系统比较见 Lehmann et al. 1999（[10.1109/42.816070](https://doi.org/10.1109/42.816070)）；Runge 现象与分段插值的关系见 §0.3。

## 二、线性插值

### 2.1 一维线性插值

#### 2.1.1 公式

在子区间 $[x_i, x_{i+1}]$ 上，用连接两端点的直线近似：

```math
S(x) = y_i + \frac{y_{i+1} - y_i}{x_{i+1} - x_i}\,(x - x_i), \qquad x \in [x_i, x_{i+1}]
```

引入**局部归一化坐标**（最常用的工程写法）：

```math
t = \frac{x - x_i}{x_{i+1} - x_i} \in [0,1], \qquad S(x) = (1-t)\,y_i + t\,y_{i+1}
```

**Lagrange 形式**（便于推广）：

```math
S(x) = \frac{x_{i+1} - x}{x_{i+1} - x_i}\,y_i + \frac{x - x_i}{x_{i+1} - x_i}\,y_{i+1}
```

两个基函数 $\ell_i(x) = \frac{x_{i+1}-x}{h_i}$、$\ell_{i+1}(x) = \frac{x-x_i}{h_i}$ 构成**帽函数**（hat function）：在节点处取 1，在相邻节点处取 0。整条曲线就是所有帽函数的线性组合。

#### 2.1.2 误差与性质

设 $f \in C^2$，$h = \max h_i$，则在 $[x_i, x_{i+1}]$ 上存在 $\xi$ 使

```math
f(x) - S(x) = \frac{f''(\xi)}{2}(x - x_i)(x - x_{i+1})
```

因此

```math
\|f - S\|_\infty \le \frac{h^2}{8}\,\|f''\|_\infty = O(h^2)
```

- **精度阶**：$O(h^2)$——比最近邻高一阶。
- **光滑性**：$S \in C^0$，导数在节点处**跳变**（折角）。曲率是分段常数 + 冲激。
- **形状保持**：区间内单调，**整体也不会产生新的极值点**——节点处取值为 $y_i$，区间内取值是两端点的凸组合，必然落在 $[\min(y_i,y_{i+1}), \max(y_i,y_{i+1})]$ 内，因此**天然无过冲**。代价是**低估峰值、削平尖峰**（对凸函数曲线总在弦的下方，系统性偏低）。
- **计算代价**：$O(\log n)$ 查找 + $O(1)$ 求值；等距网格上 $O(1)$。

#### 2.1.3 变种与工程实现

| 变种 | 公式/思路 | 特点 |
|------|-----------|------|
| **标准分段线性** | 上式 | 最简单、无过冲 |
| **重心/面积坐标（barycentric）** | 用 $t$ 而非 $x$ 做插值，避免大数相减的数值误差 | 大坐标值（如地理经纬度）时更稳 |
| **带外推的分段线性** | 在首尾区间延长切线 | 外推风险高，仅用于短期预测 |
| **LUT + 线性插值** | 预存等距采样表，查询时二分定位再线性 | 查表加速超越函数（sin、exp、gamma） |
| **查表 + 斜率表** | 额外存 $k_i = (y_{i+1}-y_i)/h_i$，省一次除法 | 嵌入式常用 |

**伪代码（1D，通用节点）**：

```text
function linear_interp(xs, ys, x):
    n = len(xs) - 1
    if x <= xs[0] or x >= xs[n]:
        return linear_extrapolate(xs, ys, x)   # 外推必须显式处理，见 §九 第 4 条
    i = binary_search(xs, x)                   # xs[i] <= x < xs[i+1]
    h = xs[i+1] - xs[i]
    t = (x - xs[i]) / h
    return (1 - t) * ys[i] + t * ys[i+1]
```

**等距网格上的 $O(1)$ 特化**：

```text
function linear_grid(x, x0, dx, n, ys):
    u = (x - x0) / dx               # 连续索引
    i = floor(u)
    t = u - i
    i = clamp(i, 0, n-2)
    return (1 - t) * ys[i] + t * ys[i+1]
```

**向量化/GPU**：整个操作无分支依赖（除 clamp），可用 `gather` + 加权和一次完成，是纹理采样的底层实现。

#### 2.1.4 应用情形

**适合：**

1. **等距/非等距采样的连续信号重采样**——音频重采样（SRC）、ADC 后处理、示波器波形重建。
2. **图像/体数据的灰度插值**——比最近邻平滑，比样条便宜。
3. **实时系统中的快速查表**——超越函数、gamma 校正、颜色空间转换的 LUT 插值。
4. **作为更复杂方法的"基线"**——几乎所有插值论文都以线性插值为对照。
5. **分段线性近似非线性函数**——如 ReLU 网络的分段线性表示、神经网络量化中的分段线性拟合。

**不适合：**

1. **要求 $C^1$ 及以上光滑**——需要导数连续时（如样条轨迹、物理仿真）会出现折角与力矩突变。
2. **高阶精度需求**——$O(h^2)$ 在网格较粗时不够；需要 $O(h^4)$ 时用三次样条。
3. **曲率大的数据**——凸函数会被系统性低估（弦在弧下方）。

### 2.2 双线性与多线性插值

#### 2.2.1 双线性插值（2D）

在矩形网格上，先沿一个方向线性插值，再沿另一个方向插值。设查询点落在单元格 $[x_i, x_{i+1}] \times [y_j, y_{j+1}]$，归一化坐标

```math
u = \frac{x - x_i}{x_{i+1} - x_i}, \qquad v = \frac{y - y_j}{y_{j+1} - y_j}
```

四角值为 $Q_{00}, Q_{10}, Q_{01}, Q_{11}$（分别对应 $(x_i,y_j)$、$(x_{i+1},y_j)$、$(x_i,y_{j+1})$、$(x_{i+1},y_{j+1})$），则

```math
S(u,v) = (1-u)(1-v)\,Q_{00} + u(1-v)\,Q_{10} + (1-u)v\,Q_{01} + uv\,Q_{11}
```

也可写成两次一维插值的复合：

```math
S(u,v) = (1-v)\big[(1-u)Q_{00} + u Q_{10}\big] + v\big[(1-u)Q_{01} + u Q_{11}\big]
```

**关键性质：**

- 双线性函数形如 $a + bu + cv + duv$，**不是**平面（含 $uv$ 交叉项），因此曲面在单元格边界上连续（$C^0$），但**跨界导数不连续**。
- 双线性插值**先沿哪个方向插结果相同**（可交换），这一点常被用来做两趟 separable 实现：先整行插值，再整列插值。
- 误差：$O(h^2)$（对光滑 $f$）。

**变种：**

| 变种 | 说明 |
|------|------|
| **可分离两趟实现** | 先水平后垂直（或反之），每趟一维线性，GPU 上可两 pass 完成，是 OpenGL/DirectX 纹理采样的标准做法 |
| **双线性 + 边界 clamp/wrap/mirror** | 边界处理策略，直接影响边缘伪影 |
| **双线性上采样（bilinear upsampling）** | CNN 解码器常用，等价于 `F.interpolate(mode='bilinear', align_corners=False)` |
| **双线性 + 反卷积组合** | 先双线性放大再卷积，可替代转置卷积以减轻棋盘格伪影 |
| **"半像素"对齐** | `align_corners` 的取舍：语义分割中通常用 `align_corners=False`（像素中心对齐），图像超分常用 `True`（角点对齐） |

**伪代码（双线性，含 clamp）**：

```text
function bilinear(img, x, y):        # img: H×W
    x = clamp(x, 0, W-1);  y = clamp(y, 0, H-1)
    i = floor(x); j = floor(y)
    u = x - i;  v = y - j
    i1 = min(i+1, W-1); j1 = min(j+1, H-1)
    return (1-u)*(1-v)*img[j][i]   + u*(1-v)*img[j][i1]
         + (1-u)*v*img[j1][i]      + u*v*img[j1][i1]
```

**复杂度**：每点 4 次乘 + 3 次加；整幅图像 $O(HW)$，完全向量化。

#### 2.2.2 三线性与多线性（3D 及以上）

三线性插值在立方体的 8 个顶点上做三趟一维插值：

```math
S(u,v,w) = \sum_{\alpha,\beta,\gamma \in \{0,1\}} (1-u)^{1-\alpha}u^{\alpha}(1-v)^{1-\beta}v^{\beta}(1-w)^{1-\gamma}w^{\gamma}\, Q_{\alpha\beta\gamma}
```

**代价**：$d$ 维多线性需 $2^d$ 次取值、$2^d$ 项加权——**维度灾难**。3D 是 8 点，4D 是 16 点，5D 是 32 点。工程上：

- **3D 医学影像/CT 重建**：三线性是标配（体积重采样、MPR 多平面重建）。
- **高维查找表（如 5D 色彩变换、BRDF）**：常用**单纯形插值**（simplex）替代多线性，因为 $d$ 维单纯形只有 $d+1$ 个顶点，而立方体有 $2^d$ 个。这是 ICC 色彩管理中的标准技术。

**单纯形插值（多线性的降维变种）**：把超立方体切成 $d!$ 个单纯形，每个查询点只落在其中一个，用 $d+1$ 个顶点做重心坐标插值。3D 时 4 点代替 8 点，速度提升明显。

#### 2.2.3 应用情形

**适合：**

1. **图像缩放/旋转/仿射变换**——`cv2.resize(INTER_LINEAR)`、`torch.nn.functional.grid_sample`。
2. **CNN 特征图上采样**——双线性上采样是 U-Net 系解码器的默认选择。
3. **医学影像重采样**——CT/MRI 的各向异性体素重采样、MPR。
4. **色彩查找表（3D LUT）**——ICC 色彩管理、HDR 色调映射。
5. **数字音频重采样**——多相滤波前的粗插值。

**不适合：**

1. **需要 $C^1$ 连续**——双线性的跨界导数不连续，在表面重建/法线计算中会露出马脚。
2. **散点数据**——双线性要求**规则网格**；散点要用三角剖分 + 重心插值（见 §2.3）或径向基。
3. **高维规则网格**——$2^d$ 爆炸，改用单纯形或张量积样条。

### 2.3 三角剖分上的分片线性

**散点**（非网格）数据的分片线性插值：先做 **Delaunay 三角剖分**，再在包含查询点的三角形上用**重心坐标**（barycentric coordinates）插值。

设三角形顶点 $P_0, P_1, P_2$，查询点 $P$ 的重心坐标 $(\lambda_0, \lambda_1, \lambda_2)$ 满足

```math
P = \lambda_0 P_0 + \lambda_1 P_1 + \lambda_2 P_2, \qquad \lambda_0 + \lambda_1 + \lambda_2 = 1, \quad \lambda_k \ge 0
```

则

```math
S(P) = \lambda_0 y_0 + \lambda_1 y_1 + \lambda_2 y_2
```

**为什么是 Delaunay？** Delaunay 三角剖分最大化最小角，避免瘦长三角形；在分片线性插值下，它等价于**使插值曲面的梯度跳变最小**，因此是最"光滑"的三角剖分选择（这一最优性由 Rippa 1990 证明）。

**变种：**

| 变种 | 说明 |
|------|------|
| **Delaunay + 重心插值** | 散点线性插值的标准答案 |
| **自然邻点插值（natural neighbor / Sibson）** | 用 Voronoi 面积权重，$C^0$ 且比重心插值更平滑 |
| **最近邻 + 三角剖分混合** | 粗网格快查 + 局部精化 |

**伪代码**：

```text
function triangulated_linear(points, values, query):
    T = delaunay_triangulation(points)      # 预处理 O(n log n)
    tri = locate_triangle(T, query)         # 定位，可 O(log n)
    (l0, l1, l2) = barycentric(tri, query)  # 重心坐标
    return l0*v[tri.a] + l1*v[tri.b] + l2*v[tri.c]
```

**应用**：有限元（FEM）的 $P_1$ 单元、地形高程插值（TIN）、气象站点数据可视化、Delaunay 三角网上的 DEM 生成。

**文献**：Delaunay B. *Sur la sphère vide.* 1934；Rippa S. *Minimal roughness property of the Delaunay triangulation.* Computer Aided Geometric Design. 1990;7(6):489–497. doi:[10.1016/0167-8396(90)90011-F](https://doi.org/10.1016/0167-8396(90)90011-F)

## 三、样条基础：为什么需要更高阶

线性插值只有 $C^0$，导数跳变；若应用要求**曲率连续**（如轨迹规划、CAD 曲面、物理场可视化），就需要提高拼接处的连续性。

### 3.1 分段多项式的自由度账本

设 $n+1$ 个节点把区间分成 $n$ 段，每段用 $k$ 次多项式（$k+1$ 个系数），总未知量 $n(k+1)$。约束有两类：

1. **过点约束**：每段的两个端点都要取给定值。注意相邻两段在公共节点上的约束是**两个不同的方程**（分别作用于两段各自的多项式），所以共 $2n$ 个，而不是 $n+1$ 个。这是最容易数错的地方。
2. **连续性约束**：要求 $S, S', \dots, S^{(k-1)}$ 在 $n-1$ 个内节点处连续。$S$ 连续已被过点约束覆盖，因此额外需要 $k-1$ 阶导数连续，共 $(n-1)(k-1)$ 个。

剩余自由度：

```math
n(k+1) - 2n - (n-1)(k-1) = (nk + n) - 2n - (nk - n - k + 1) = k - 1
```

| 次数 $k$ | 连续性 | 剩余自由度 | 需要补充的条件 |
|----------|--------|-----------|----------------|
| 1（线性） | $C^0$ | **0** | 无——唯一确定 |
| 2（二次） | $C^1$ | **1** | 1 个条件（起点斜率 $s_0$，或首段为线性） |
| 3（三次） | $C^2$ | **2** | 2 个边界条件（两端各一个） |
| 5（五次） | $C^4$ | **4** | 4 个端点条件（各阶导） |

> **关键洞察**：$C^{k-1}$ 连续的分段 $k$ 次多项式在插值条件下仍**留下 $k-1$ 个自由度**，必须补充边界条件才能唯一确定。这就是样条"不唯一"的根源——**不同补充方式 = 不同的样条变种**。
>
> 反过来说：**线性插值之所以"免费"**，恰恰因为 $k=1$ 时 $k-1=0$，自由度正好用尽。这是它无需任何边界条件、无需解方程的根本原因。

> **推论**：若要求 $C^k$ 连续（比 $C^{k-1}$ 更高一阶），则每段需多满足 $n-1$ 个约束，自由度为 $k-1-(n-1) < 0$——因此 $k$ 次多项式**不可能**同时做到逐点插值与 $C^k$ 连续（除 $n$ 很小）。想要更高连续性只能升次数（如五次样条给 $C^4$）或放宽插值（改拟合）。

### 3.2 样条的三类构造思路

1. **解线性方程组（B 样条 / 自然样条路线）**：把连续性条件写成线性方程，解三对角或带状系统。稳定、快速（$O(n)$），是工程主流。
2. **局部分段构造（Hermite / 参数样条路线）**：直接给每段指定端点值和端点导数（Hermite 形式），导数由差分估计。实现简单、可流式处理。
3. **变分最优路线**：把样条定义为"在满足插值条件下使某个能量泛函最小"的函数。三次样条正是**最小化弯曲能量** $\int (S'')^2 dx$ 的解——这是它被称为"最优插值"的理论基础。

### 3.3 光滑性阶数速查

| 方法 | 连续性 | 一阶导 | 二阶导 |
|------|--------|--------|--------|
| 最近邻 | $C^{-1}$（跳变） | 冲激 | — |
| 分段线性 | $C^0$ | 分段常数（跳变） | 冲激 |
| 二次样条 | $C^1$ | 连续 | 分段常数（跳变） |
| 三次样条 | $C^2$ | 连续 | 连续 |
| 五次样条 | $C^4$ | 连续 | 连续 |

## 四、二次样条

### 4.1 原理：单参数族的构造

二次样条是**分段二次多项式**，要求跨节点 $C^1$ 连续。由 §3.1 的账本（$k=2$），插值 + $C^1$ 之后**还剩下 1 个自由度**，因此二次样条构成一个**单参数族**：只要指定一个额外条件（最自然的是起点斜率 $s_0$），整条曲线就唯一确定。

记每段的二阶导为常数 $M_i$（段内 $S'' \equiv M_i$），$h_i = x_{i+1}-x_i$，$\Delta_i = (y_{i+1}-y_i)/h_i$。以左端点为展开点：

```math
S_i(x) = y_i + s_i\,(x - x_i) + \frac{M_i}{2}(x - x_i)^2, \qquad x \in [x_i, x_{i+1}]
```

其中 $s_i = S'(x_i^+)$ 是该段左端的斜率。用 $S_i(x_{i+1}) = y_{i+1}$ 消去 $M_i$ 或消去 $s_i$，得到两个等价的约束：

```math
s_i = \Delta_i - \frac{M_i h_i}{2}
\qquad\Longleftrightarrow\qquad
M_i = \frac{2(\Delta_i - s_i)}{h_i}
```

这就是二次样条的**全部结构**：段内二阶导由"起点斜率与割线斜率的差"决定。

### 4.2 连续性条件与唯一化

**$C^1$ 条件**：在内部节点 $x_{i+1}$ 处，让左右两段的导数相等。左段在右端点的导数、右段在左端点的导数分别为

```math
S'(x_{i+1}^-) = s_i + M_i h_i, \qquad S'(x_{i+1}^+) = s_{i+1}
```

代入 $s_i = \Delta_i - M_i h_i/2$：

```math
S'(x_{i+1}^-) = \Delta_i + \frac{M_i h_i}{2}
```

令两者相等，并用 $M_{i+1} = 2(\Delta_{i+1}-s_{i+1})/h_{i+1}$ 把 $M_{i+1}$ 也表出：

```math
\Delta_i + \frac{M_i h_i}{2} = \Delta_{i+1} - \frac{M_{i+1} h_{i+1}}{2}
```

```math
\boxed{\;\frac{h_i}{2} M_i + \frac{h_{i+1}}{2} M_{i+1} = \Delta_{i+1} - \Delta_i, \qquad i = 0, 1, \dots, n-2\;}
```

**方程数与自由度**：这是 $n-1$ 个方程，未知量是 $M_0, \dots, M_{n-1}$（$n$ 个，因为每段一个）——正好**差一个条件**，与 §3.1 的一致性检验吻合。这个系统是**二对角**的（每条方程只含相邻两个未知量），从 $M_0$ 出发可以直接**前向递推**解出全部 $M$，**不需要解三对角系统**：

```math
M_{i+1} = \frac{2(\Delta_{i+1} - \Delta_i) - h_i M_i}{h_{i+1}}
```

**更常用的斜率递推形式**：把 $M_i$ 用斜率表示，则 $C^1$ 条件给出极简的递推

```math
s_{i+1} = 2\Delta_i - s_i
```

推导：$S'(x_{i+1}^-) = s_i + M_i h_i = s_i + 2(\Delta_i - s_i) = 2\Delta_i - s_i$。

**这个递推式是二次样条的全部性格来源**。写成误差形式

```math
s_{i+1} - \Delta_i = -(s_i - \Delta_i)
```

可以看到：给定 $s_0$，后面所有节点的斜率被**唯一确定**，并且"斜率相对割线的偏离量"在相邻节点间**逐段变号、大小不变**——这就是它必然振荡的数学根源。

**边界条件（任选其一，用于定出单参数）：**

| 边界条件 | 形式 | 名称 | 说明 |
|----------|------|------|------|
| 指定起点斜率 | $s_0 = f'(x_0)$（或差分估计） | 夹持（clamped） | 最常用；精度最好 |
| 首段退化为线性 | $M_0 = 0 \iff s_0 = \Delta_0$ | 自然（natural） | 实现最简单，等价于令首段为直线 |
| 指定末点斜率 | 由 $s_{n-1} = 2\Delta_{n-2}-s_{n-2}$ 反解 $s_0$ | 端点夹持 | 从尾部倒推 |
| 周期 | $2\Delta_{n-1} - s_{n-1} = s_0$ | 周期（periodic） | 闭环信号。注意递推的交替性：**$n$ 为奇数时唯一可解，$n$ 为偶数时一般无解**（因 $s_n = (-1)^n s_0 + C$，偶数段时退化为对常数的等式要求） |

> **注意**：二次样条**不能**同时指定首末两个斜率——那样会超定（除非数据恰好满足递推关系）。这是它只有 1 个自由度、而三次样条有 2 个自由度的直接后果。


### 4.3 误差与性质

- **精度阶**：$O(h^3)$（对 $f \in C^3$；节点的函数值本身精确，导数误差 $O(h^2)$）。
- **光滑性**：$C^1$——一阶导连续，二阶导**分段常数、在节点处跳变**。
- **形状保持**：**不保凸、不保单调**。由 $s_{i+1} - \Delta_i = -(s_i - \Delta_i)$，斜率的"偏差"在相邻段**等幅反号**地传下去。这意味着：
  - 只要起点斜率不恰好等于某个"平衡值"，偏差就永不衰减，形成**持续交替振荡**；
  - 数据单调递增时，仍可能出现 $s_i < 0$ 的段 —— 即**曲线局部反向**；
  - 这是它最大的实践缺陷，也是它比三次样条用得少的主要原因。
- **局部性**：**极差**。$s_i$ 对 $s_0$ 的依赖系数是 $(-1)^i$，**不衰减**——首端斜率的任何误差会以同样幅度传到末端。这是比三次样条（影响随距离衰减）严重得多的非局部性。
- **计算代价**：$O(n)$ 构造（纯前向递推，连三对角求解都不需要），$O(1)$ 单点求值（定位段后一次二次求值）。

> **为什么二次样条如此"神经质"**：它是唯一一个自由度恰好为 1 的 $C^1$ 分段多项式族，没有多余参数去吸收边界误差，于是误差只能"反弹"传导。三次样条有 2 个自由度、且三对角矩阵严格对角占优，误差被系统性地阻尼掉——这就是"多一阶"带来的稳定性飞跃。

**数值验证**（$f=\cos$、$[0,1]$ 等距节点、起点斜率取真值 $s_0 = f'(0)$，稠密点取最大误差）：

| $N$ | 5 | 9 | 17 | 33 | 65 | 129 |
|----:|--:|--:|--:|--:|--:|----:|
| 最大误差 | 1.11e-4 | 1.35e-5 | 1.66e-6 | 2.07e-7 | 2.58e-8 | 3.22e-9 |
| 收敛比 | — | 8.23 | 8.09 | 8.04 | 8.02 | 8.01 |

收敛比稳定在 $8 = 2^3$，**实测确认 $O(h^3)$**。注意即使起点斜率取得完全精确，振荡依然存在——它是**结构性的**，不是边界误差造成的。

### 4.4 变种与工程实现

| 变种 | 说明 | 优点/缺点 |
|------|------|-----------|
| **自然二次样条** | 首段为直线，$M_0 = 0$（即 $s_0 = \Delta_0$） | 无需估计导数；但端点精度退化 |
| **夹持二次样条** | 给定起点斜率 $s_0 = f'(x_0)$ | 精度最好（$O(h^3)$）；需可靠的一阶导 |
| **末点夹持** | 由 $s_{n-1} = 2\Delta_{n-2}-s_{n-2}$ 反解 $s_0$ | 当末端斜率已知（如末速为零）时用 |
| **周期二次样条** | $s_n = s_0$ | 周期信号（心电、旋转机械）；**仅 $n$ 为奇数可解** |
| **保形二次样条** | 对 $M_i$ 施加符号/幅度约束，强制 $S$ 落在相邻值域内 | 牺牲精度换形状；见下方"钳制"实现 |
| **二次 B 样条** | 用 B 样条基表示（$p=2$，见 §6.1） | 局部支撑、凸包性；用于曲线建模 |
| **中点格式** | 以段中点为展开点、按中点值约束 | 在信号处理/细分曲面（subdivision）中有对应结构 |

**保形钳制的工程做法**（把"振荡"变成"局部单调"）：设 $y_{\min}=\min(y_i,y_{i+1})$、$y_{\max}=\max(y_i,y_{i+1})$，若段内极值点 $\hat t = -s_i/M_i$ 落在 $(0,h_i)$ 内，则把极值钳制到 $y_i$ 或 $y_{i+1}$（视方向），据此反解并覆盖 $M_i$，然后**继续向前递推**。这样代价仍是 $O(n)$，但得到的是分段 $C^1$、$\mathbb{R}$ 内不越界的保形曲线。

**伪代码（前向递推构造 + 求值）**：

```text
function quadratic_spline_build(xs, ys, s0):
    # xs 升序，长度 n+1；s0 = 起点斜率（自然型取 delta[0]）
    n = len(xs) - 1
    for i in 0..n-1: h[i] = xs[i+1] - xs[i];  delta[i] = (ys[i+1]-ys[i]) / h[i]
    s[0] = s0
    for i in 0..n-1:
        M[i]   = 2 * (delta[i] - s[i]) / h[i]    # 段内二阶导（常数）
        s[i+1] = s[i] + M[i] * h[i]              # 恒等于 2*delta[i] - s[i]
    return (s[], M[])      # 段 i 上：S(x) = ys[i] + s[i]*(x-xs[i]) + M[i]/2*(x-xs[i])^2

function quadratic_spline_eval(xs, ys, s, M, x):
    i = binary_search(xs, x)                     # xs[i] <= x < xs[i+1]
    t = x - xs[i]
    return ys[i] + s[i]*t + 0.5*M[i]*t*t
```

**复杂度**：构造 $O(n)$ 时间、$O(n)$ 空间（无需求解任何线性系统）；求值 $O(\log n)$，等距网格上 $O(1)$。

**校验**：上式递推自动满足端点插值与 $C^1$ 连续（$S_i(x_{i+1})=y_{i+1}$ 且 $s_{i+1}=s_i+M_ih_i$ 就是 $C^1$ 条件的重写），无需额外检查。

### 4.5 应用情形

**适合：**

1. **计算预算极紧、又需要 $C^1$ 的场合**——纯前向递推，无矩阵、无除法链，适合 MCU/FPGA 与硬实时控制。
2. **轨迹规划的粗规划**——给出 $C^1$ 路径用于速度规划，后续再用三次/五次精化。
3. **周期信号的局部拼接**——心电、振动等按段处理。
4. **教学与理论桥梁**——它是"$C^1$ 拼接 + 单参数补充"的最小完整例子，理解它才能理解为什么三次样条需要 2 个边界条件。

**不适合：**

1. **有噪声的数据**——交替振荡会被忠实保留甚至放大，产生大量虚假极值。
2. **任何严格保形需求**——不保单调、不保凸；浓度、概率、累积分布、存活率等必须有界/单调的量不能用（除非加钳制）。
3. **需要 $C^2$ 连续**——曲率跳变会导致力矩/加速度突变（机械系统冲击、动画抖动）。
4. **需要局部修改或长序列**——误差沿链条等幅传播，改一点影响全部后续，且对起点斜率极其敏感。
5. **长数据序列**——误差不衰减这一点在 $n$ 很大时是致命的；工程上应优先用三次样条或 PCHIP。

## 五、三次样条

三次样条（cubic spline）是**工程与科学计算中最重要、最常用的高阶插值方法**，也是"样条"一词的默认所指。

### 5.1 定义与最优性

**定义**：$S(x)$ 是分段三次多项式，满足

1. $S(x_i) = y_i$（插值条件）；
2. $S \in C^2[x_0, x_n]$（二阶连续可导）；
3. 满足一组边界条件（见 §5.3）。

**最优性定理（Holladay 1957）**：在所有满足插值条件、且二阶导数平方可积的 $C^2$ 函数中，**自然三次样条**（$S''(x_0) = S''(x_n) = 0$）使弯曲能量

```math
E[S] = \int_{x_0}^{x_n} \big[S''(x)\big]^2 \, dx
```

**取最小值**。这就是三次样条被称为"最光滑插值"的严格含义：它是**在插值约束下总曲率最小的曲线**，等价于一根受约束的弹性细梁（物理上的"样条"就是绘图员用的弹性尺）。

**推论**：在给定边界条件下，$C^2$ 分段三次插值函数是**唯一**的。因此三次样条没有"选哪个解"的自由度问题（而二次样条有），它的形状完全由数据和边界条件决定。

> **但要注意**："总曲率最小"**不等于**"不过冲"。最小弯曲能量是**全局积分**指标，它允许局部为压低整体曲率而产生反向过冲——这正是三次样条在阶跃附近出现振铃的原因（见 §5.4 与 §九 第 6 条）。**最优性是积分意义下的，不是逐点保号意义下的**。

### 5.2 标准构造：以节点二阶导为未知量

记 $M_i = S''(x_i)$，$h_i = x_{i+1} - x_i$，$\Delta_i = (y_{i+1}-y_i)/h_i$。

在段 $[x_i, x_{i+1}]$ 上，$S''$ 是线性函数（因为 $S$ 是三次）：

```math
S''(x) = M_i \frac{x_{i+1} - x}{h_i} + M_{i+1}\frac{x - x_i}{h_i}
```

积分两次并用 $S(x_i) = y_i$、$S(x_{i+1}) = y_{i+1}$ 定常数，得到段内表达式：

```math
S(x) = M_i\frac{(x_{i+1}-x)^3}{6h_i} + M_{i+1}\frac{(x-x_i)^3}{6h_i}
     + \Big(y_i - \frac{M_i h_i^2}{6}\Big)\frac{x_{i+1}-x}{h_i}
     + \Big(y_{i+1} - \frac{M_{i+1}h_i^2}{6}\Big)\frac{x-x_i}{h_i}
```

**关键：$C^1$ 连续（$S'$ 在节点处左右相等）导出三对角方程**：

```math
\frac{h_{i-1}}{6} M_{i-1} + \frac{h_{i-1}+h_i}{3} M_i + \frac{h_i}{6} M_{i+1}
= \frac{y_{i+1}-y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}
= \Delta_i - \Delta_{i-1}
```

即

```math
\mu_i M_{i-1} + 2 M_i + \lambda_i M_{i+1} = d_i, \qquad i = 1, \dots, n-1
```

其中

```math
\lambda_i = \frac{h_i}{h_{i-1}+h_i}, \quad
\mu_i = \frac{h_{i-1}}{h_{i-1}+h_i} = 1 - \lambda_i, \quad
d_i = \frac{6}{h_{i-1}+h_i}\Big(\frac{y_{i+1}-y_i}{h_i} - \frac{y_i-y_{i-1}}{h_{i-1}}\Big)
```

> 注意 $\mu_i + \lambda_i = 1$ 且系数矩阵**严格对角占优**（对角元 $2 > \mu_i + \lambda_i = 1$），因此三对角系统**无条件非奇异**，用 Thomas 算法解 $O(n)$，数值稳定。

**等距简化**（$h_i = h$）：$M_{i-1} + 4M_i + M_{i+1} = \frac{6}{h^2}(y_{i-1} - 2y_i + y_{i+1})$。

### 5.3 边界条件（4 种标准型）

$n+1$ 个未知 $M_0, \dots, M_n$，内节点给 $n-1$ 个方程，需 2 个边界条件：

| 类型 | 条件 | 名称 | 特点 |
|------|------|------|------|
| **自然（natural）** | $M_0 = M_n = 0$ | 自然三次样条 | 端点曲率为零；端点附近误差较大；Holladay 最优性针对它 |
| **夹持（clamped / complete）** | $S'(x_0) = f'(x_0)$，$S'(x_n) = f'(x_n)$ | 完整/夹持三次样条 | 端点精度最好（$O(h^4)$ 局部）；需要可靠的一阶导 |
| **非节点（not-a-knot）** | 首段与次段的三次多项式相同（$S'''$ 在 $x_1$ 连续），末两段同理 | not-a-knot | **MATLAB `spline`、SciPy `CubicSpline` 的默认**；无需求导，端点精度接近 clamped |
| **周期（periodic）** | $S'(x_0)=S'(x_n)$，$S''(x_0)=S''(x_n)$ | 周期三次样条 | 首尾闭合；用于周期信号 |

**四类边界条件对应的方程**（与内节点方程一起构成 $n+1$ 阶三对角/近三对角系统）：

**① 自然（natural）**：直接令 $M_0 = 0$、$M_n = 0$，首末行变为单位行。系统严格三对角。

**② 夹持（clamped）**：由 $S'(x_0) = y_0'$ 与段内表达式解出 $M_0, M_1$ 的关系。利用 $S'(x_0^+) = -\frac{h_0}{3}M_0 - \frac{h_0}{6}M_1 + \Delta_0$，得

```math
2M_0 + M_1 = \frac{6}{h_0}\Big(\Delta_0 - y_0'\Big)
```

末端对称地：

```math
M_{n-1} + 2M_n = \frac{6}{h_{n-1}}\Big(y_n' - \Delta_{n-1}\Big)
```

（等距时这两式就是熟知的 $2M_0+M_1 = \frac{6}{h^2}(y_1-y_0-hy_0')$。）

**③ 非节点（not-a-knot）**：令 $S'''$ 在 $x_1$ 与 $x_{n-1}$ 处连续。由于段内 $S'''(x) \equiv (M_{i+1}-M_i)/h_i$ 是常数，条件化为

```math
\frac{M_1 - M_0}{h_0} = \frac{M_2 - M_1}{h_1}
\quad\Longleftrightarrow\quad
h_1 M_0 - (h_0 + h_1) M_1 + h_0 M_2 = 0
```

末端对称：

```math
h_{n-1} M_{n-2} - (h_{n-2}+h_{n-1}) M_{n-1} + h_{n-2} M_n = 0
```

这两行使矩阵**不再是严格三对角**（首行含 $M_2$），但仍可用带一个额外对角线的带状求解器 $O(n)$ 处理。等价解释：$x_1$ 与 $x_{n-1}$ 不再是"真正的节点"——它们两侧的三次多项式相同（即"不是节点"，not-a-knot 由此得名），实际只剩 $n-2$ 个自由度对应 $n-2$ 段。

**④ 周期（periodic）**：$M_0 = M_n$、$S'(x_0^+) = S'(x_n^-)$，把首末两式合并成一个**循环三对角（cyclic tridiagonal）**系统，用 Sherman–Morrison 公式化归为两次三对角求解，仍是 $O(n)$。


**误差界**（Hall & Meyer 1976；亦见 de Boor 1978 第 2 章）：若 $f \in C^4$，则对**完整（clamped）**样条

```math
\|f - S\|_\infty \le \frac{5}{384}\,h^4 \|f^{(4)}\|_\infty = O(h^4)
```

常数 $\frac{5}{384} \approx 0.013$ 是最优的（不可再改进）。对 not-a-knot 也有同阶界，常数略大。而**自然样条**在端点邻域只有 $O(h^2)$——这就是 §八 的实测表中 natural 收敛比只有 4 的原因。

### 5.4 性质总结

- **精度阶**：$O(h^4)$（clamped/not-a-knot），自然样条端点为 $O(h^2)$。
- **光滑性**：$C^2$——曲率连续，这是它相对二次样条的决定性优势。
- **形状保持**：**不保单调、不保凸、可能过冲**。这是三次样条最需要注意的缺陷：对陡变数据（如阶跃附近）会产生**振铃（ringing）**，在数据范围内可能超出 $[\min y, \max y]$。图像处理中这表现为边缘附近的"光晕"（over/undershoot）。
- **局部性**：**差**。改动 $y_i$ 会影响所有 $M_j$（三对角系统是全局耦合的），整条曲线都会变——虽然影响随距离衰减，但不严格局部。
- **计算代价**：$O(n)$ 构造（Thomas 算法），$O(\log n)$ 求值；若预存四元组 $(a,b,c,d)$ 则 $O(1)$。
- **过点性**：是。

### 5.5 工程实现要点

**两种等价的存储方案：**

1. **二阶导形式** $(M_i)$：存 $M$ 数组 + 原 $y$，求值时用 §5.2 的公式。数值较稳，是教科书标准。
2. **多项式系数形式** $(a_i, b_i, c_i, d_i)$：

```math
S(x) = a_i + b_i (x - x_i) + c_i (x-x_i)^2 + d_i (x-x_i)^3, \quad x \in [x_i, x_{i+1}]
```

这是 **MATLAB `pp` 结构**、**SciPy `PPoly`**、**Eigen/Boost** 的通用表示。系数由 $M$ 换算：

```math
a_i = y_i, \quad d_i = \frac{M_{i+1}-M_i}{6h_i}, \quad c_i = \frac{M_i}{2}, \quad b_i = \Delta_i - \frac{(2M_i + M_{i+1})h_i}{6}
```

**伪代码（完整流程：组装 + 求解 + 求值）**：

```text
function cubic_spline_build(xs, ys, bc_type, bc_values):
    n = len(xs) - 1
    for i in 0..n-1: h[i] = xs[i+1] - xs[i];  delta[i] = (ys[i+1]-ys[i]) / h[i]

    # ---- 1) 内节点方程（i = 1..n-1），三条对角
    #      natural/clamped/not-a-knot：矩阵 (n+1)×(n+1)，未知量 M[0..n]
    #      periodic：矩阵 n×n，未知量 M[0..n-1]（M[n] 由 M[0] 代表）
    for i in 1..n-1:
        A[i][i-1] = h[i-1]
        A[i][i]   = 2*(h[i-1] + h[i])
        rhs[i]    = 6*(delta[i] - delta[i-1])
    if bc_type != "periodic":
        for i in 1..n-1:  A[i][i+1] = h[i]      # 非周期：上对角正常填写
    else:
        for i in 1..n-2:  A[i][i+1] = h[i]      # 周期：i = n-1 的上对角绕回第 0 列，见下方角项

    # ---- 2) 两个边界行，按 bc_type 分支
    if bc_type == "natural":                      # 严格三对角
        A[0][0] = 1;                       rhs[0] = 0
        A[n][n] = 1;                       rhs[n] = 0
    elif bc_type == "clamped":                    # 严格三对角
        A[0][0] = 2;  A[0][1] = 1;         rhs[0] = 6*(delta[0] - bc_values[0]) / h[0]
        A[n][n] = 2;  A[n][n-1] = 1;       rhs[n] = 6*(bc_values[1] - delta[n-1]) / h[n-1]
    elif bc_type == "not-a-knot":                 # 首末行各有 3 项 → 需带宽 2 的带状求解
        A[0][0] = h[1];  A[0][1] = -(h[0]+h[1]);  A[0][2] = h[0];        rhs[0] = 0
        A[n][n-2] = h[n-1]; A[n][n-1] = -(h[n-2]+h[n-1]); A[n][n] = h[n-2]; rhs[n] = 0
    elif bc_type == "periodic":
        # 周期条件给出 M[n] = M[0]，未知量缩为 M[0..n-1]（共 n 个），矩阵为 n×n 循环三对角：
        #   · i = 1..n-2 行不变；
        #   · i = n-1 行原上对角项 h[n-1]*M[n] 绕回 M[0]  → A[n-1][0] += h[n-1]
        #   · 第 0 行 = 原 i=0 与 i=n 两式合并：
        #       2*(h[n-1]+h[0])*M[0] + h[0]*M[1] + h[n-1]*M[n-1] = 6*(delta[0]-delta[n-1])
        A[n-1][0] += h[n-1]                    # 右上角项
        A[0][0]    = 2*(h[n-1] + h[0])
        A[0][1]    = h[0]
        A[0][n-1]  = h[n-1]                    # 左下角项
        rhs[0]     = 6*(delta[0] - delta[n-1])
        # 两个角项即"循环"的标志；用 Sherman–Morrison 拆成两次普通三对角求解，仍是 O(n)

    # ---- 3) 求解（O(n)）：natural/clamped 用 Thomas；not-a-knot 用带宽 2 的带状求解
    M = banded_solve(A, rhs)

    # ---- 4) 转成段内系数（pp 形式），便于 O(1) 求值
    if bc_type == "periodic":  M[n] = M[0]      # 周期：补上 M[n] 以统一下面的下标访问
    for i in 0..n-1:
        a_i = ys[i]
        b_i = delta[i] - h[i]*(2*M[i] + M[i+1]) / 6
        c_i = M[i] / 2
        d_i = (M[i+1] - M[i]) / (6*h[i])
    return (xs, a[], b[], c[], d[])

function cubic_spline_eval(xs, c, x):
    if x < xs[0] or x > xs[n]:  return extrapolate(x)     # 外推必须显式声明
    i = binary_search(xs, x)                              # xs[i] <= x < xs[i+1]
    t = x - xs[i]
    return c.a[i] + t*(c.b[i] + t*(c.c[i] + t*c.d[i]))    # Horner，3 乘 3 加
```

**Thomas 算法（严格三对角求解）轮廓**：

```text
function thomas_solve(l, m, u, d):    # 下对角 l[]、主对角 m[]、上对角 u[]、右端 d[]
    for i in 1..N-1:                  # 前向消元
        w = l[i] / m[i-1]
        m[i] -= w * u[i-1]
        d[i] -= w * d[i-1]
    x[N-1] = d[N-1] / m[N-1]
    for i in N-2..0:                  # 回代
        x[i] = (d[i] - u[i]*x[i+1]) / m[i]
    return x
```

**复杂度**：构造 $O(n)$，内存 $O(n)$；求值 $O(\log n)$（二分）或 $O(1)$（等距 + 直接索引）。**这是所有高阶插值中性价比最高的方案**，也是它成为默认选择的原因。

### 5.6 变种与工程扩展

| 变种 | 说明 | 何时用 |
|------|------|--------|
| **自然样条** | $M_0=M_n=0$ | 端点无信息时的保守默认；但端点精度差 |
| **夹持样条** | 指定端点导数 | 有可靠的边界斜率信息（如速度、温度梯度） |
| **not-a-knot** | 首末两段各合并 | **默认首选**：无需额外信息，端点精度好 |
| **周期样条** | 首尾闭合 | 周期信号（角度、时间序列、旋转机械） |
| **准均匀 / 参数化样条** | 参数 $t$ 而非 $x$，可处理重复节点、闭合曲线 | 2D/3D 曲线插值（路径、轮廓） |
| **张力样条（spline under tension）** | 加入张力参数 $\sigma$，抑制过冲 | 地形、等高线，需抑制振铃 |
| **平滑样条（smoothing spline）** | 不插值，最小化 $\sum (y_i - S(x_i))^2 + \lambda \int (S'')^2$ | 有噪声数据；$\lambda$ 控制光滑度 |
| **保形三次样条（PCHIP）** | 用单调性约束确定导数 | **保单调/保形需求**（见 §6.2） |
| **B 样条（B-spline）** | 局部支撑基函数表示（见 §6.1） | CAD、NURBS、需要局部修改 |
| **Akima 样条** | 用局部斜率加权，抗过冲 | 快速变化的实验数据 |
| **Catmull–Rom 样条** | 局部四点构造的 $C^1$ 样条 | 图形学中的关键帧动画、路径平滑 |

### 5.7 应用情形

**适合（几乎是"默认选择"的场合）：**

1. **科学计算中的函数近似**——ODE/PDE 求解后的稠密输出、查表函数的平滑替代。
2. **计算机图形学与动画**——关键帧插值（Catmull–Rom）、相机路径、角色运动轨迹；$C^2$ 保证加速度连续、无抖动。
3. **CAD/CAM 曲线曲面**——B 样条与 NURBS 的基础（见 §6.1），数控加工的刀路光滑性。
4. **信号与图像处理**——图像放大（bicubic）、音频重采样（高阶插值核）；图像处理中的 bicubic 就是三次卷积插值。
5. **地理与气象数据**——等值线/等值面生成、DEM 插值、温度场重建。
6. **金融**——收益率曲线拟合（尽管实践中更常用单调保形方法，见 §6.2）。
7. **控制系统轨迹规划**——需要加速度连续（$C^2$）的平滑参考轨迹。

**不适合：**

1. **必须保单调/保凸的数据**——浓度、概率、累积分布、期权隐含波动率微笑、利率曲线。此时应改用 **PCHIP / 单调三次 Hermite**（§6.2）。
2. **含噪数据**——插值会逐点穿过噪声，产生剧烈振荡；应改用平滑样条或 LOESS。
3. **数据有阶跃/不连续**——三次样条会在阶跃附近产生 Gibbs 式振铃，应改用保形方法或分段处理。
4. **极高维**——三次样条的张量积在多维是 $4^d$ 邻域，$d \ge 4$ 时代价迅速上升（见 §7）。

## 六、样条的工程变体族

### 6.1 B 样条：局部支撑的通用表示

**动机**：三次样条的 $M$ 表示是全局耦合的（改一点动全身）。B 样条（Basis spline，de Boor 1972）用**局部支撑的基函数**表示样条，使局部修改只影响局部，同时数值上极其稳定。

**定义（Cox–de Boor 递推）**：给定节点序列 $t_0 \le t_1 \le \cdots \le t_{m}$，$p$ 次 B 样条基为

```math
B_{i,0}(x) = \begin{cases} 1, & t_i \le x < t_{i+1} \\ 0, & \text{otherwise} \end{cases}
```

```math
B_{i,p}(x) = \frac{x - t_i}{t_{i+p} - t_i} B_{i,p-1}(x) + \frac{t_{i+p+1} - x}{t_{i+p+1} - t_{i+1}} B_{i+1,p-1}(x)
```

样条函数为

```math
S(x) = \sum_{i} c_i B_{i,p}(x)
```

**关键性质：**

- **局部支撑**：$B_{i,p}$ 仅在 $[t_i, t_{i+p+1})$ 上非零——这是局部性的来源。
- **单位分解**：$\sum_i B_{i,p}(x) \equiv 1$。
- **$C^{p-1}$ 连续**（在单节点处）；重复节点降低连续性（重数为 $r$ 时降为 $C^{p-r}$）。
- **凸包性**：曲线落在控制点 $c_i$ 的凸包内——**天然无过冲**（这对保形极其重要）。

**插值 vs 逼近**：B 样条曲线 $S(x) = \sum c_i B_{i,p}$ 的系数 $c_i$ **不是**函数值，而是"控制点"。要**插值**给定 $y_i$，需解线性系统 $B c = y$（带状矩阵，$O(n)$）。要**逼近**（拟合），用最小二乘求 $c$。

| 变种 | 说明 |
|------|------|
| **均匀 B 样条** | 等距节点，基函数是平移副本——卷积/滤波实现，GPU 友好 |
| **非均匀 B 样条（NUBS）** | 任意节点间距 |
| **NURBS（有理 B 样条）** | $S(x) = \sum w_i c_i B_i / \sum w_i B_i$，可精确表示圆锥曲线；CAD 工业标准（IGES/STEP） |
| **张力 B 样条** | 引入张力参数抑制振荡 |
| **B 样条 + 变分** | 平滑样条的基函数表示，$O(n)$ 求解 |

**应用**：CAD（NURBS 曲面）、字体（TrueType 用二次 B 样条，PostScript Type 1 用三次 Bézier）、动画曲线、等几何分析（IGA）、密度估计（B 样条基）。

**文献**：de Boor C. *On calculating with B-splines.* Journal of Approximation Theory. 1972;6(1):50–62. doi:[10.1016/0021-9045(72)90080-9](https://doi.org/10.1016/0021-9045(72)90080-9)；Cox MG. *The numerical evaluation of B-splines.* IMA Journal of Applied Mathematics. 1972;10(2):134–149. doi:[10.1093/imamat/10.2.134](https://doi.org/10.1093/imamat/10.2.134)

### 6.2 PCHIP：保形分段三次 Hermite

**问题**：三次样条在单调数据上可能产生非单调段，在保形要求下不可接受。**PCHIP（Piecewise Cubic Hermite Interpolating Polynomial）** 通过**约束导数的符号与大小**保证形状。

**Hermite 形式**：在段 $[x_i, x_{i+1}]$ 上，用两端点值与两端点导数 $(y_i, y_{i+1}, d_i, d_{i+1})$ 唯一确定三次多项式：

```math
S(x) = h_{00}(t)\,y_i + h_{10}(t)\,h_i d_i + h_{01}(t)\,y_{i+1} + h_{11}(t)\,h_i d_{i+1}, \qquad t = \frac{x-x_i}{h_i}
```

其中三次 Hermite 基函数

```math
h_{00}(t) = 2t^3 - 3t^2 + 1, \quad h_{10}(t) = t^3 - 2t^2 + t, \quad h_{01}(t) = -2t^3 + 3t^2, \quad h_{11}(t) = t^3 - t^2
```

**PCHIP 的导数规则（Fritsch–Carlson 1980）**：

1. **单调性判据**：若 $\Delta_{i-1}$ 与 $\Delta_i$ 异号，或任一为零，则 $d_i = 0$（该点是局部极值，导数置零，避免过冲）。
2. **同号时**：$d_i$ 取**加权调和平均**

```math
\frac{1}{d_i} = \frac{1}{w_1+w_2}\left(\frac{w_1}{\Delta_{i-1}} + \frac{w_2}{\Delta_i}\right),
\qquad w_1 = 2h_i + h_{i-1}, \quad w_2 = h_i + 2h_{i-1}
```

其中 $w_1$ 配**左段斜率** $\Delta_{i-1}$、$w_2$ 配**右段斜率** $\Delta_i$（这是 Fritsch–Carlson 原始权重，也是 SciPy `PchipInterpolator` 采用的版本）。当 $h_{i-1}=h_i=h$ 时 $w_1=w_2=3h$，退化为等权调和平均 $d_i = \dfrac{2\Delta_{i-1}\Delta_i}{\Delta_{i-1}+\Delta_i}$。
3. **端点**：用单侧三点公式（Moler 的做法是"非中心三点差分 + 同号约束 + 幅度限制"），并同样施加符号约束。
4. **保证（Fritsch–Carlson 充分条件）**：对每段令 $\alpha = d_i/\Delta_i$、$\beta = d_{i+1}/\Delta_i$，若 $\alpha,\beta \ge 0$ 且 $\alpha^2+\beta^2 \le 9$，则插值在该段**单调**。加权调和平均自动满足此条件。因此若数据单调，则插值函数**逐段单调**，且 $S$ 在所有区间内**不超出相邻两点的值域**——无过冲。

**对比三次样条**：

| 项目 | 三次样条 | PCHIP |
|------|----------|-------|
| 光滑性 | $C^2$ | $C^1$ |
| 保单调 | 否 | **是** |
| 过冲 | 可能 | **无** |
| 局部性 | 否（全局耦合） | **是**（导数只依赖相邻三点） |
| 精度 | $O(h^4)$ | $O(h^3)$（光滑数据） |

**应用**：收益率曲线、期权隐含波动率、人口/流行病累计曲线、药物浓度、颜色映射（colormap）、任何"物理上不允许过冲"的量。

**文献**：Fritsch FN, Carlson RE. *Monotone piecewise cubic interpolation.* SIAM Journal on Numerical Analysis. 1980;17(2):238–246. doi:[10.1137/0717021](https://doi.org/10.1137/0717021)

### 6.3 Akima 样条

**动机**：三次样条对离群点敏感（全局耦合）；PCHIP 虽保形但导数估计偏保守（极值处强制为 0，损失精度）。Akima（1970）提出用**局部加权斜率**估计导数，在"抗过冲"和"保精度"之间折中。

**导数公式**：设 $\Delta_i = \dfrac{y_{i+1}-y_i}{h_i}$ 为第 $i$ 段的割线斜率（$i = 0,\dots,n-1$）。节点 $x_i$ 处的导数取**相邻两个斜率差的绝对值加权**的算术平均：

```math
d_i = \frac{\big|\Delta_{i+1}-\Delta_i\big|\;\Delta_{i-1} + \big|\Delta_{i-1}-\Delta_{i-2}\big|\;\Delta_i}
{\big|\Delta_{i+1}-\Delta_i\big| + \big|\Delta_{i-1}-\Delta_{i-2}\big|}
```

**几何含义**：权重是"相邻段斜率变化的剧烈程度"。若 $|\Delta_{i+1}-\Delta_i|$ 很大（右侧曲率突变），则 $\Delta_{i-1}$ 的权重占优——即**用变化平缓那一侧的信息主导**，从而抑制陡变处的过冲。当分母为 0（两侧斜率都无变化）时，退化为 $\frac{1}{2}(\Delta_{i-1}+\Delta_i)$。

**端点处理**：$x_0, x_1$ 需要 $\Delta_{-1}, \Delta_{-2}$，用**线性外推**虚构：

```math
\Delta_{-1} = 2\Delta_0 - \Delta_1, \qquad \Delta_{-2} = 2\Delta_{-1} - \Delta_0
```

末端对称：$\Delta_{n} = 2\Delta_{n-1}-\Delta_{n-2}$，$\Delta_{n+1} = 2\Delta_n - \Delta_{n-1}$。（这一外推策略是 Akima 原文的做法，被 SciPy `Akima1DInterpolator` 沿用；也有实现改用单侧三点公式求端点导数。）

- **光滑性**：$C^1$。
- **特点**：**不严格保单调**（不像 PCHIP 有单调性定理），但由于权重机制，过冲**远小于**三次样条；对局部异常值鲁棒；计算 $O(n)$ 且**局部**（$d_i$ 只依赖 $\Delta_{i-2..i+1}$，即 $y_{i-2..i+2}$ 五个点）。
- **与 PCHIP 的区别**：PCHIP 用**调和平均 + 极值置零**，保证严格单调但导数偏保守；Akima 用**绝对值加权算术平均**，不保单调但更贴合原始趋势，在数据本身有噪声起伏时曲线更自然。

**应用**：实验数据处理、气象/海洋垂直剖面、工程测量曲线的平滑连接、任何"数据有局部起伏但不想被抹平"的场合。

**文献**：Akima H. *A new method of interpolation and smooth curve fitting based on local procedures.* Journal of the ACM. 1970;17(4):589–602. doi:[10.1145/321607.321609](https://doi.org/10.1145/321607.321609)

### 6.4 Catmull–Rom 样条

**动机**：图形学需要**快速、局部、$C^1$** 的曲线插值，且最好能处理参数曲线（2D/3D 路径）。Catmull–Rom（1974）用相邻四点构造一段三次多项式。

设四点 $P_{i-1}, P_i, P_{i+1}, P_{i+2}$（可为标量或向量），段 $[P_i, P_{i+1}]$ 上的切向量取

```math
m_i = \frac{P_{i+1} - P_{i-1}}{2}, \qquad m_{i+1} = \frac{P_{i+2} - P_i}{2}
```

再用 Hermite 基函数插值。等价的矩阵形式（$t \in [0,1]$）：

```math
S(t) = \begin{bmatrix} 1 & t & t^2 & t^3 \end{bmatrix}
\frac{1}{2}\begin{bmatrix}
0 & 2 & 0 & 0\\
-1 & 0 & 1 & 0\\
2 & -5 & 4 & -1\\
-1 & 3 & -3 & 1
\end{bmatrix}
\begin{bmatrix} P_{i-1} \\ P_i \\ P_{i+1} \\ P_{i+2} \end{bmatrix}
```

- **性质**：$C^1$，局部（只依赖 4 点），不过冲保证较弱（可能轻微过冲），**参数曲线友好**。
- **变种**：
  - **向心 Catmull–Rom（centripetal）**：节点参数化改用 $t_{i+1} = t_i + |P_{i+1}-P_i|^{1/2}$（弦长的平方根），可**消除尖点与自交**，是图形学的推荐默认（Yuksel et al., 2011）。对照：均匀参数化（上式，$t_{i+1}=t_i+1$）在点距悬殊时会出现"打圈"；弦长参数化（指数 1）居中。
  - **张力 Catmull–Rom**：对切向量乘张力因子 $\tau \in [0,1]$，$\tau \to 0$ 时曲线趋向"平缓过点"（切向量趋零，过渡变软），$\tau=1$ 为标准 Catmull–Rom。
- **应用**：关键帧动画（Unity、Blender 的曲线插值）、相机路径、字体曲线、样条平滑（轨迹后处理）、NeRF/3DGS 中的轨迹插值。

**文献**：Catmull E, Rom R. *A class of local interpolating splines.* In: Barnhill RE, Riesenfeld RF, eds. Computer Aided Geometric Design. Academic Press; 1974:317–326. doi:[10.1016/B978-0-12-079050-0.50020-5](https://doi.org/10.1016/B978-0-12-079050-0.50020-5)

### 6.5 平滑样条（Smoothing Spline）

**动机**：数据有噪声时，插值（过点）是把噪声也当成信号。平滑样条（Reinsch 1967；Wahba 1990）改成**变分问题**：

```math
\min_{S} \; \sum_{i=0}^{n} \big(y_i - S(x_i)\big)^2 + \lambda \int_{x_0}^{x_n} \big[S''(x)\big]^2 dx
```

- 第一项：拟合程度；第二项：弯曲能量（粗糙度惩罚）；$\lambda \ge 0$ 是光滑参数。
- $\lambda \to 0$：退化为自然三次样条（过点）；$\lambda \to \infty$：退化为最小二乘直线。
- 解是**自然三次样条**，节点在数据点上，系数由线性系统（$O(n)$，带宽固定）给出——这就是 **Reinsch 算法**。
- $\lambda$ 的选择：**广义交叉验证（GCV）**、AIC、或限制最大自由度。
- **与 LOESS / 核回归的关系**：平滑样条是"惩罚似然"路线，LOESS 是"局部多项式"路线，二者在偏差-方差权衡上等价类。

**应用**：信号去噪、趋势提取、非参数回归、广义可加模型（GAM）、样条基的惩罚回归。

**文献**：Reinsch CH. *Smoothing by spline functions.* Numerische Mathematik. 1967;10(3):177–183. doi:[10.1007/BF02162161](https://doi.org/10.1007/BF02162161)；Wahba G. *Spline Models for Observational Data.* SIAM; 1990. doi:[10.1137/1.9781611970128](https://doi.org/10.1137/1.9781611970128)

### 6.6 三次卷积插值（bicubic / Keys 核）

**动机**：图像处理里的 "bicubic" 与三次样条**不是同一个东西**。它不求解任何线性系统，而是用**一个固定的三次卷积核**在邻域上做加权平均——本质是**分段三次、$C^1$ 的紧支撑核**，局部、$O(1)$、完全可并行。

**Keys 三次卷积核**（Keys 1981，参数 $a$ 通常取 $-0.5$；$a=-0.75$ 见 Photoshop 系实现）：

```math
W(x) = \begin{cases}
(a+2)|x|^3 - (a+3)|x|^2 + 1, & 0 \le |x| \le 1 \\[2pt]
a|x|^3 - 5a|x|^2 + 8a|x| - 4a, & 1 < |x| < 2 \\[2pt]
0, & |x| \ge 2
\end{cases}
```

插值式为 4 点加权（等距节点，索引 $i = \lfloor x/h \rfloor$，$t = x/h - i$）：

```math
S(x) = \sum_{k=-1}^{2} W(k - t)\, y_{i+k}
```

**已校验的性质**（可直接用于实现自测）：

| 性质 | 检验式 | 结果 |
|------|--------|------|
| **Kronecker 性**（插值性） | $W(0)=1$，$W(\pm1)=W(\pm2)=0$ | 成立（节点处精确过点） |
| **单位分解** | $\sum_{k} W(x+k) \equiv 1$ | 成立（$a$ 任意） |
| **一阶线性再生** | $\sum_k k\,W(x+k) = x$ | 成立（即能精确重建直线） |
| **$C^1$ 连续** | $W'(1^-)=W'(1^+)$ | 成立（在 $x=1$ 处值 $-a/2$） |
| **$C^2$** | — | **不成立**（二阶导在节点处跳变） |
| **过冲** | — | 存在（$a<0$ 时在阶跃处产生轻微振铃；$a=0$ 过冲最小但更模糊） |

**与三次样条的区别（面试与工程选型常考）：**

| 项目 | 三次样条（cubic spline） | 三次卷积（bicubic / Keys） |
|------|--------------------------|-----------------------------|
| 定义方式 | 解全局三对角系统，$C^2$ | 固定核卷积，$C^1$ |
| 局部性 | 否（全局耦合） | **是**（4 点邻域） |
| 预处理 | $O(n)$ 解方程组 | **无** |
| 精度阶 | $O(h^4)$ | $O(h^3)$（$a=-0.5$ 时三阶精度） |
| 非等距节点 | 直接支持 | 需先重采样到等距网格 |
| 典型实现 | `scipy.interpolate.CubicSpline` | `cv2.resize(INTER_CUBIC)`、`PIL`、GPU 纹理硬件 |

**变种与要点：**

- **$a$ 的取值权衡**：$a=-0.5$（Keys 推荐、三次精度）、$a=-0.75$（更锐利，过冲更多，Photoshop/Catmull-Rom 系）、$a=0$（无过冲但明显模糊，等价于某种平滑）。
- **Bicubic 的 "half-pixel" 问题**：缩放公式须区分 `align_corners` 语义，否则整体偏移半像素——这是图像分割标签与预测错位的常见来源。
- **可分离实现**：2D bicubic = 先横向 4 点卷积、再纵向 4 点卷积，共 16 点，$O(HW)$ 且 GPU 上极快。
- **硬件纹理采样**：GPU 的 `GL_LINEAR` 是双线性；`GL_LINEAR_MIPMAP` 组合多层；三次卷积需手动实现（shader 中 4 次 `texture()` 或 bicubic 上采样技巧）。
- **bicubic 上采样层**：CNN 中 `F.interpolate(mode='bicubic')` 用于超分（如 ESRGAN 的预处理），注意其默认 `align_corners=False` 与 PyTorch 警告。

**应用**：图像缩放/旋转、图像超分预处理、视频缩放、纹理过滤、色调映射中的局部重采样。

**文献**：Keys R. *Cubic convolution interpolation for digital image processing.* IEEE Transactions on Acoustics, Speech, and Signal Processing. 1981;29(6):1153–1160. doi:[10.1109/TASSP.1981.1163711](https://doi.org/10.1109/TASSP.1981.1163711)

### 6.7 保形与形状约束样条汇总

| 方法 | 保单调 | 保凸 | 光滑性 | 局部性 | 典型场景 |
|------|--------|------|--------|--------|----------|
| 分段线性 | 是 | 是 | $C^0$ | 是 | 快速、无过冲 |
| 二次样条 | 否 | 否 | $C^1$ | 否 | 快速 $C^1$ |
| 三次样条 | 否 | 否 | $C^2$ | 否 | 默认高精度 |
| **PCHIP** | **是** | 部分 | $C^1$ | 是 | 单调数据、金融曲线 |
| **Akima** | 近似 | 近似 | $C^1$ | 是 | 含噪实验数据 |
| **三次卷积（bicubic）** | 否 | 否 | $C^1$ | 是 | 图像/纹理重采样 |
| **B 样条（凸包）** | 是* | 是* | $C^{p-1}$ | 是 | CAD、曲线建模 |
| **张力样条** | 可调 | 可调 | $C^2$ | 否 | 抑制振铃 |
| **平滑样条** | 否 | 否 | $C^2$ | 否 | 去噪、趋势 |

\* B 样条的凸包性保证曲线在控制点凸包内，但**控制点不等于数据点**；若需插值，需解系统，凸包性不再直接对应数据范围。

## 七、多维与散点插值（工程常用补充）

### 7.1 张量积样条（规则网格）

2D/3D 规则网格上的三次样条是**一维样条的张量积**：

```math
S(x,y) = \sum_{i}\sum_{j} c_{ij} B_i(x) B_j(y)
```

实现上就是**先沿行做 1D 样条，再沿列做 1D 样条**（separable），每维 $O(n)$。代价：$d$ 维每点需 $4^d$ 邻域（三次），3D 是 64 点——比三线性（8 点）贵 8 倍，但精度 $O(h^4)$。

**应用**：图像 bicubic 放大（$4\times4$ 邻域）、医学影像的 $B$ 样条插值（Unser 的快速 B 样条变换）、气象场重建。

### 7.2 径向基函数（RBF）插值

**动机**：散点 + 高维时，三角剖分在多维退化（$d$ 维 Delaunay 代价高、瘦长单纯形问题严重）。RBF 用**全局基函数**：

```math
S(\mathbf{x}) = \sum_{i=1}^{N} w_i \varphi(\|\mathbf{x} - \mathbf{x}_i\|) + p(\mathbf{x})
```

其中 $p$ 是低次多项式（保证适定性），$\varphi$ 是核函数：

| 核 | 公式 | 特点 |
|----|------|------|
| 高斯 | $e^{-\varepsilon^2 r^2}$ | 光滑、局部性好；$\varepsilon$ 敏感 |
| 多二次（MQ） | $\sqrt{r^2 + \varepsilon^2}$ | 精度高、条件数较好 |
| 薄板样条（TPS） | $r^2 \log r$ | 2D 下等价于"最小弯曲能量"；与三次样条同源 |
| 逆多二次（IMQ） | $1/\sqrt{r^2+\varepsilon^2}$ | 稳定、常用 |
| 紧支撑（Wendland） | 多项式截断 | 稀疏矩阵、大规模 |

**求解**：$N$ 个插值条件得 $N \times N$ 线性系统（稠密），$O(N^3)$ 直接解；大规模用快速多极子（FMM）或紧支撑核把矩阵变稀疏。

**薄板样条（TPS）** 特别值得注意：它是 2D 下**最小化 $\iint (S_{xx}^2 + 2S_{xy}^2 + S_{yy}^2)$** 的解——是三次样条"最小弯曲能量"在多维的自然推广，因此被称为"2D 的三次样条"。

**应用**：地形/地质建模、医学图像配准（TPS 形变）、点云重建、气象插值、机器学习中的核方法。

**文献**：Duchon J. *Splines minimizing rotation-invariant semi-norms in Sobolev spaces.* 1977. doi:[10.1007/BFb0086566](https://doi.org/10.1007/BFb0086566)；Bookstein FL. *Principal warps: thin-plate splines and the decomposition of deformations.* IEEE TPAMI. 1989;11(6):567–585. doi:[10.1109/34.24792](https://doi.org/10.1109/34.24792)

### 7.3 克里金（Kriging）

地统计学的插值方法，本质是**带协方差模型的最优线性无偏估计（BLUP）**：

```math
\hat{S}(\mathbf{x}_0) = \sum_i \lambda_i y_i, \qquad \sum_i \lambda_i = 1
```

权重 $\lambda$ 由**变差函数**（variogram）$\gamma(h)$ 或协方差矩阵解出：

```math
\begin{bmatrix} \Gamma & \mathbf{1} \\ \mathbf{1}^T & 0 \end{bmatrix}
\begin{bmatrix} \boldsymbol{\lambda} \\ \mu \end{bmatrix}
= \begin{bmatrix} \boldsymbol{\gamma}_0 \\ 1 \end{bmatrix}
```

- **普通克里金（ordinary）**：只约束权重和为 1；**简单克里金**：已知均值；**泛克里金**：含趋势项。
- 与 RBF 的关系：普通克里金与 RBF 在数学上同构（"dual form"），区别在于**权重由统计模型（变差函数）导出而非纯几何核**，因此带有不确定性估计（kriging variance）。
- **应用**：地质储量、土壤污染、气象站点插值、矿产勘探。

**文献**：Matheron G. *Principles of geostatistics.* Economic Geology. 1963;58(8):1246–1266. doi:[10.2113/gsecongeo.58.8.1246](https://doi.org/10.2113/gsecongeo.58.8.1246)

### 7.4 保形多维插值

多维情况下"保单调"定义更复杂（需沿所有方向），常用手段：

- **分段多线性 + 单调性裁剪**（clamp 到邻域值域）；
- **单纯形插值 + 保形约束**；
- **RBF + 形状约束优化**（难，计算代价高）；
- 实践中最常见：**先用单调 1D 方法逐维处理**（张量积），再检查过冲。

### 8.4 收敛阶的数值验证（可复现对照）

光看理论阶不够，工程上应当**实测收敛比**：把节点数加倍（$h \to h/2$），若最大误差缩小约 $2^p$ 倍，则该方法的实际阶就是 $p$。

以 $f(x)=e^x$、$x \in [0,1]$ 等距节点、稠密点上取最大误差为例（相邻两行误差之比即收敛比）：

| 节点数 $N$ | $h$ | 分段线性 | 三次样条（natural） | 三次样条（clamped） | 三次样条（not-a-knot） | PCHIP | Akima |
|-----------:|----:|---------:|--------------------:|--------------------:|-----------------------:|------:|------:|
| 5 | 0.250 | 1.88e-2 | 8.22e-3 | 2.64e-5 | 2.21e-4 | 1.54e-3 | 1.54e-3 |
| 9 | 0.125 | 4.99e-3 | 2.08e-3 | 1.69e-6 | 1.65e-5 | 2.11e-4 | 2.11e-4 |
| 17 | 0.0625 | 1.29e-3 | 5.21e-4 | 1.07e-7 | 1.10e-6 | 2.77e-5 | 2.77e-5 |
| 33 | 0.0313 | 3.27e-4 | 1.30e-4 | 6.72e-9 | 7.09e-8 | 3.55e-6 | 3.55e-6 |
| 65 | 0.0156 | 8.23e-5 | 3.26e-5 | 4.21e-10 | 4.51e-9 | 4.48e-7 | 4.48e-7 |
| 129 | 0.0078 | 2.07e-5 | 8.14e-6 | 2.63e-11 | 2.84e-10 | 5.64e-8 | 5.64e-8 |
| **实测收敛比** | | **≈4（$h^2$）** | **≈4（$h^2$）** | **≈16（$h^4$）** | **≈16（$h^4$）** | **≈8（$h^3$）** | **≈8（$h^3$）** |

**如何解读这张表**（这是本笔记最实用的一张表）：

1. **线性插值确实是 $h^2$**，不是 $h$。很多人误以为"线性 = 一阶"，其实**函数值逼近是二阶**，一阶的是**导数**逼近。这一点在查表精度估算时常被搞错。
2. **自然三次样条实测只有 $h^2$**（比值 ≈4），因为最大误差出现在**端点**，被 $M_0=M_n=0$ 这个错误的曲率假设主导。这正是 §九 第 1 条强调"默认用 not-a-knot"的实证依据。
3. **clamped 与 not-a-knot 都是 $h^4$**。not-a-knot 的绝对误差比 clamped 大约一个数量级（因为它没有真实的端点导数信息），但**阶相同**——两者在加密时同样受益。
4. **PCHIP/Akima 是 $h^3$**。为"保形"付出的代价是掉一阶。在光滑数据上这是纯粹的精度损失；但只要数据有单调性约束，这一阶换来的形状正确性通常更值。
5. **光滑数据上 Akima 与 PCHIP 误差几乎相同**（本例完全一致）——差异只在数据**不光滑或含局部突变**时才显现，此时 Akima 更贴合趋势、PCHIP 更保守。
6. **加密网格的收益是有上限的**：当 $h$ 小到误差接近浮点舍入（约 $10^{-16}$ 量级）或数据噪声水平时，继续加密不再有效。见 §九 第 9 条。

> **实操建议**：在自己的数据上跑一次这种"加倍节点、看误差比"的小实验，比背误差阶公式可靠得多。它同时能暴露实现 bug——若实测比值远小于理论 $2^p$，多半是边界条件写错或索引错位。

## 九、数值细节与常见坑

1. **端点条件的选择比插值方法本身更影响结果**。自然样条的端点误差是 $O(h^2)$，而 clamped/not-a-knot 是 $O(h^4)$——差两个数量级。**默认优先 not-a-knot**（无需求导且端点好）。

2. **等距 vs 非等距**。非等距节点上 $h_i$ 变化剧烈时，三对角系统的条件数会变差；某些实现会用**参数化**（按弧长或弦长归一化）改善。

3. **大坐标的数值误差**。经纬度、时间戳这类大数值（$10^6$ 量级）做 `(x - x_i)/h` 时，浮点相减会损失有效位。解决：**先减去基准点**（重心/平移坐标），或直接用重心坐标插值。

4. **外推必须显式处理**。几乎所有样条库默认对 $x < x_0$ 或 $x > x_n$ 做**线性延长**或**常数延长**，而非用首/末段多项式外推（后者会爆炸）。使用时务必确认库的默认行为。

5. **过冲是可量化的**。$\max_x S(x) - \max_i y_i$ 与 $\min_i y_i - \min_x S(x)$ 是两个常用指标。图像处理中 bicubic 的过冲需要 clamp 到 $[0,255]$。

6. **三次样条的"振铃"在阶跃附近**。若数据含阶跃（如掩膜边缘、开关信号），三次样条会在两侧产生衰减振荡（类似 Gibbs 现象）。解决：改用 PCHIP/张力样条，或在阶跃处**分段**（拆成两段单独插值）。

7. **重复节点**。参数样条中 $x_i = x_{i+1}$ 时 $h_i = 0$，会除零。B 样条通过重复节点降低连续性来处理；Hermite 形式需特殊处理。

8. **单调性检验**。工程上常用 Fritsch–Carlson 条件检验：对每段，若 $\Delta_i = 0$ 则 $d_i = d_{i+1} = 0$；否则要求 $\alpha = d_i/\Delta_i$、$\beta = d_{i+1}/\Delta_i$ 满足 $\alpha^2 + \beta^2 \le 9$（充分条件）。这是 PCHIP 的核心充分条件。

9. **精度阶的实际意义**。$O(h^4)$ 只在 $f \in C^4$ 且 $h$ 足够小时成立。实际数据往往不光滑（测量噪声、离散化误差），此时**加密网格不会线性提升精度**——误差由噪声主导。这正是平滑样条存在的意义。

10. **插值 vs 回归的选择**。如果数据有噪声，"必须过点"就是错误假设。先用平滑样条/LOESS/PCHIP 平滑，再在平滑曲线上插值，通常比直接插值更接近真值。

## 十、速查总结

**插值方法的选择本质上是在四个维度上做取舍**：光滑性、保形性、局部性、计算代价。没有全面最优的方法，只有与场景匹配的方法。

### 10.1 五种核心方法的定位

| 方法 | 核心结论 | 何时必选 | 何时禁用 |
|------|----------|----------|----------|
| **最近邻** | 唯一的 $C^{-1}$，唯一正确的**离散标签**插值 | 分割 mask、实例 ID、类别图、LUT 阶跃映射 | 任何连续物理量 |
| **线性** | $C^0$、$O(h^2)$、**天然无过冲**、最廉价 | 查表加速、通用快速重采样、双/三线性图像缩放 | 需要导数连续、高精度 |
| **二次样条** | $C^1$、$O(h^3)$、**误差不衰减**、结构性强振荡 | 极紧算力的 $C^1$ 需求、粗轨迹规划 | 有噪声、需保形、长序列 |
| **三次样条** | $C^2$、$O(h^4)$（clamped/not-a-knot）、通用默认 | 科学计算稠密输出、轨迹（加速度连续）、CAD/图形学 | 保单调/保凸需求、含噪数据、有阶跃 |
| **PCHIP** | $C^1$、$O(h^3)$、**保单调无过冲**、局部 | 收益率曲线、累积分布、浓度、colormap | 需要 $C^2$ 或极致精度 |

### 10.2 三条经验法则

1. **先问数据的物理性质，再问算法**。标签 → 最近邻；有界/单调 → PCHIP；必须 $C^2$ → 三次样条。方法选错，调参无用。
2. **"必须过点"本身是一个假设**。数据含噪时它就是错的，应换成平滑样条/LOESS；否则你精确地拟合了噪声。
3. **边界条件比方法更影响端点精度**。三次样条优先 not-a-knot；自然样条只在"端点曲率确实为零"时有意义。见 §八 8.4 的实测：natural 只收敛到 $O(h^2)$，clamped/not-a-knot 才到 $O(h^4)$。

### 10.3 方法谱系一图流

```text
                    分段常数 ─ 最近邻（C^-1, O(h)）
                   /
分段多项式 ────────  分段线性 ─ 线性 / 双线性 / 三线性 / 三角剖分（C^0, O(h^2)）
                   \
                    分段二次 ─ 二次样条（C^1, O(h^3)）
                              └ 二次 B 样条
                    分段三次 ─ 三次样条（C^2, O(h^4)）── 自然 / 夹持 / not-a-knot / 周期
                              ├ 三次卷积 bicubic（C^1, 固定核，局部）
                              ├ Hermite 族 ── PCHIP（保单调）/ Akima（抗振铃）/ Catmull–Rom（动画）
                              └ B 样条 / NURBS（局部支撑、凸包性）

变分/核方法 ──────── 平滑样条（惩罚似然）
                    薄板样条 TPS（2D 最小弯曲能量）
                    径向基 RBF（散点、高维）
                    克里金（带统计模型的 BLUP）
```
