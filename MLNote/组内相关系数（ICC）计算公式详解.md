# 组内相关系数（ICC）计算公式详解

## 一、应用背景

在**两个评分者对同一批样本评分一致性**的研究中，ICC 是最常用的统计量之一。它衡量的是：**同一批样本的真实变异中，有多少比例能被评分者稳定地捕捉到**，即"评分的一致性程度"。

需要特别注意的是：ICC 并不是一个单一的公式，而是一族公式。选择哪一个，取决于两个关键问题：

1. **模型选择**：是双向随机效应模型还是单向随机效应模型？
2. **一致性定义**：是看**绝对一致性**（absolute agreement）还是**一致性**（consistency）？
3. **结果用途**：是取单个评分者的信度，还是取多个评分者平均值的信度？

---

## 二、数据设置

设有：

- $n$ = 样本数（被评对象）
- $k$ = 评分者数（本例中 $k=2$）
- $x_{ij}$ = 第 $i$ 个样本被第 $j$ 个评分者给出的评分

典型的双评分者数据表：

| 样本 | 评分者A | 评分者B |
|------|---------|---------|
| 1 | $x_{11}$ | $x_{12}$ |
| 2 | $x_{21}$ | $x_{22}$ |
| ... | ... | ... |
| $n$ | $x_{n1}$ | $x_{n2}$ |

---

## 三、方差分解（双向随机效应模型）

ICC 的核心思想是把总变异分解为三部分：

```math
SS_{总} = SS_{样本} + SS_{评分者} + SS_{误差}
```

### 1. 各平方和公式

**总平方和：**

```math
SS_{总} = \sum_{i=1}^{n}\sum_{j=1}^{k}(x_{ij} - \bar{x})^2
```

**样本间平方和（行效应）：**

```math
SS_{样本} = k\sum_{i=1}^{n}(\bar{x}_{i\cdot} - \bar{x})^2
```

**评分者间平方和（列效应）：**

```math
SS_{评分者} = n\sum_{j=1}^{k}(\bar{x}_{\cdot j} - \bar{x})^2
```

**误差平方和：**

```math
SS_{误差} = SS_{总} - SS_{样本} - SS_{评分者}
```

其中：

- $\bar{x}_{i\cdot}$ = 第 $i$ 个样本的平均分
- $\bar{x}_{\cdot j}$ = 第 $j$ 个评分者的平均分
- $\bar{x}$ = 总平均分

### 2. 自由度与均方

| 变异来源 | 自由度 | 均方 |
|----------|--------|------|
| 样本间 | $n-1$ | $MS_{样本} = SS_{样本}/(n-1)$ |
| 评分者间 | $k-1$ | $MS_{评分者} = SS_{评分者}/(k-1)$ |
| 误差 | $(n-1)(k-1)$ | $MS_{误差} = SS_{误差}/[(n-1)(k-1)]$ |

### 3. 方差分量估计

```math
\hat{\sigma}^2_{误差} = MS_{误差}
```

```math
\hat{\sigma}^2_{样本} = \frac{MS_{样本} - MS_{误差}}{k}
```

```math
\hat{\sigma}^2_{评分者} = \frac{MS_{评分者} - MS_{误差}}{n}
```

---

## 四、ICC 的六种形式（Shrout & Fleiss, 1979）

### ICC(1,1) 和 ICC(1,k)：单向随机效应

评分者被视为从总体中随机抽取，但评分者之间不做区分（不估计评分者效应）。

```math
ICC(1,1) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + (k-1)MS_{误差}}
```

```math
ICC(1,k) = \frac{MS_{样本} - MS_{误差}}{MS_{样本}}
```

### ICC(2,1) 和 ICC(2,k)：双向随机效应，绝对一致性

评分者是随机抽取的，且要考虑评分者的系统偏差（如A总比B高1分）。

**绝对一致性（Absolute Agreement）：**

```math
ICC(2,1) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + (k-1)MS_{误差} + \frac{k(MS_{评分者} - MS_{误差})}{n}}
```

```math
ICC(2,k) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + \frac{MS_{评分者} - MS_{误差}}{n}}
```

### ICC(3,1) 和 ICC(3,k)：双向混合效应，一致性

评分者是固定的（研究关心的就是这两个特定评分者），不考虑评分者系统偏差。

**一致性（Consistency）：**

```math
ICC(3,1) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + (k-1)MS_{误差}}
```

```math
ICC(3,k) = \frac{MS_{样本} - MS_{误差}}{MS_{样本}}
```

---

## 五、针对"两个评分者"的推荐选择

在两个评分者的场景下，最常见、最推荐的是：

### 首选：ICC(2,1) —— 双向随机效应、绝对一致性、单个评分者

**理由：**

- 两个评分者通常被视为从更大评分者总体中抽取的（随机效应）
- 我们关心两个评分者给出的分数**是否可以直接互换使用**，因此要用绝对一致性，而非一致性
- 如果研究目的是"单个评分者的信度"，用 (2,1)；如果是"两个评分者平均分的信度"，用 (2,2)

**公式（$k=2$）：**

```math
ICC(2,1) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + MS_{误差} + \frac{2(MS_{评分者} - MS_{误差})}{n}}
```

### 若只关心相对排序一致性：ICC(3,1)

```math
ICC(3,1) = \frac{MS_{样本} - MS_{误差}}{MS_{样本} + MS_{误差}}
```

---

## 六、一个直觉化理解

ICC 本质上是：

```math
ICC = \frac{\text{样本间真实变异}}{\text{样本间真实变异} + \text{误差变异} + (\text{评分者系统偏差})}
```

- 分子越大（样本之间差异明显），ICC 越高
- 分母中的误差和评分者偏差越大，ICC 越低

---

## 七、结果解读标准

| ICC 值 | 一致性程度 |
|--------|------------|
| < 0.50 | 差（poor） |
| 0.50–0.75 | 中等（moderate） |
| 0.75–0.90 | 良好（good） |
| > 0.90 | 优秀（excellent） |

> 注：不同学者给出的切点略有差异（如 Koo & Li, 2016 建议 0.5/0.75/0.9）。

## 八、计算示例（$k=2$）

假设 5 个样本、2 个评分者：

| 样本 | A | B | 行均值 |
|------|---|---|--------|
| 1 | 9 | 8 | 8.5 |
| 2 | 6 | 7 | 6.5 |
| 3 | 8 | 8 | 8.0 |
| 4 | 7 | 6 | 6.5 |
| 5 | 10 | 9 | 9.5 |

- 总均值 $\bar{x} = 7.7$
- 列均值：$\bar{x}_{\cdot A} = 8.0$，$\bar{x}_{\cdot B} = 7.6$

计算得：

- $SS_{样本} = 2[(8.5-7.7)^2+(6.5-7.7)^2+(8-7.7)^2+(6.5-7.7)^2+(9.5-7.7)^2] = 2(0.64+1.44+0.09+1.44+3.24)=13.7$
- $SS_{评分者} = 5[(8-7.7)^2+(7.6-7.7)^2] = 5(0.09+0.01)=0.5$
- $SS_{总} = (9-7.7)^2+(8-7.7)^2+\cdots = 14.1$
- $SS_{误差} = 14.1-13.7-0.5 = -0.1$（示例数据近似，实际应为非负）

> 说明：此处仅演示计算流程，真实数据请用软件计算以避免舍入误差。

- $MS_{样本} = 13.7/4 = 3.425$
- $MS_{评分者} = 0.5/1 = 0.5$
- $MS_{误差} = -0.1/4 = -0.025 \approx 0$

代入 ICC(2,1)：

```math
ICC(2,1) = \frac{3.425 - 0}{3.425 + 0 + \frac{2(0.5-0)}{5}} = \frac{3.425}{3.425+0.2} \approx 0.945
```

即一致性"优秀"。

## 九、常见应用情形

ICC 主要用于**连续型（或近似连续的有序）测量**的信度评估。医学与心理测量中最常见的三类场景如下（Koo & Li, 2016）：

| 应用类型 | 含义 | 典型例子 | 常用 ICC 选择 |
|----------|------|----------|---------------|
| **评分者间信度**（inter-rater） | 不同评分者对同一批对象打分是否一致 | 两名放射科医生测量肿瘤直径；两名专家对分割结果打质量分 | 评分者可推广到更大群体 → **ICC(2,1)**（绝对一致性）；仅关心当前固定评分者 → **ICC(3,1)** |
| **评分者内信度**（intra-rater） | 同一评分者在不同时间对同一批对象重复评分是否稳定 | 同一医生隔一周重读同一批影像并再次测量 | 双向混合 + **绝对一致性** + 单次测量（不宜把"时间点"当成可随机推广的评分者） |
| **重测信度**（test-retest） | 同一测量工具在不同时间对同一批对象重复测量是否稳定 | 量表/问卷间隔数天重测；同一设备重复扫描后的定量指标 | 同上：双向混合 + **绝对一致性** + 单次测量 |

### 各领域中的具体例子

- **医学影像 / 定量测量**：病灶长短径、体积、HU 值、ADC、图像质量评分等；诊断影像观察者间一致性研究中，ICC 是连续指标最常用的统计量之一。
- **临床量表与患者报告结局（PRO）**：疼痛评分、功能量表、生活质量量表的重测信度；FDA 相关方法学讨论中也常以 ICC 评估 PRO 的 test-retest。
- **行为观察与编码**：多名编码员对录像进行连续或有序评分（如严重程度、时长），用 ICC 评估编码一致性。
- **机器学习标注**：多名标注员对同一批样本给出连续标签（置信度、严重程度、回归目标等）时，用 ICC 报告标注一致性；若标签是类别变量，更宜用 Kappa 等分类一致性指标。

### 选用时的对应关系（简表）

| 研究问题 | 更合适的方向 |
|----------|--------------|
| 分数是否可直接互换使用？ | 选**绝对一致性**（agreement） |
| 只关心排序/相对高低是否一致？ | 可选**一致性**（consistency） |
| 关心"单个评分者/单次测量"的信度？ | 用 `(·,1)` |
| 关心"多人平均分/多次平均"的信度？ | 用 `(·,k)` |
| 评分者每次都不相同、无法对应列效应？ | 用单向随机 **ICC(1,·)** |

> 分类诊断（有/无病、分期等级等）一般用 **Cohen/Fleiss Kappa** 或加权 Kappa，而不是 ICC。ICC 更适合分数、尺寸、量表总分等可比较大小的测量。

---

## 十、关键注意事项

1. **先做模型判断**：评分者是随机还是固定？这决定用 ICC(2,x) 还是 ICC(3,x)。
2. **区分"一致性"与"绝对一致性"**：若两个评分者存在固定系统偏差（如一个总高1分），一致性 ICC 可能很高，但绝对一致性 ICC 会下降。若分数要互换使用，必须看绝对一致性。
3. **报告时需注明**：ICC 的具体形式、模型、单位（single/average）、置信区间。
4. **ICC 与 Pearson r 的区别**：Pearson r 只反映线性相关，对系统偏差不敏感；ICC 同时考虑相关性和一致性。
5. **样本量**：ICC 估计的稳定性依赖样本量，一般建议 $n \geq 30$，样本越多置信区间越窄。
